How it's built

  1. Game core

    src/game.rs grades guesses with the two-pass duplicate-letter rule. Word lists are baked in with include_str!.

  2. Slint UI

    ui/window.slint is compiled to Rust at build time; src/ui.rs wires keyboard and reset callbacks.

  3. WASM entry

    src/web.rs is a #[wasm_bindgen(start)] function that installs a panic hook and runs the window.

  4. Canvas

    Slint's winit backend binds to <canvas id="canvas"> and renders the board with WebGL.

# one-time setup
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli

# build web/pkg/ and serve this page
scripts/build-wasm.sh
python3 -m http.server --directory web 8080
